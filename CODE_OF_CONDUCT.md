# Code Of Conduct

Doorframe uses a simple contribution standard: be direct, respectful, and practical.

- Keep technical discussion focused on evidence and tradeoffs.
- Do not include sensitive, proprietary, classified-sounding, or real customer data in examples or issues.
- Assume contributors are trying to improve the tool.
- Disagreements should resolve toward code, tests, docs, and reproducible examples.

Maintainers may close or remove comments, issues, or pull requests that are abusive, unsafe, spammy, or outside the project boundaries.
