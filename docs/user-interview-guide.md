# User Interview Guide

Use this guide with adjacent users who already deal with requirements, Jira, test evidence, reviews, or audit prep.

## Workflow Questions

- Can you show how you currently trace requirements to work items and tests?
- What do you do before a requirements review?
- What spreadsheet do you dread updating?
- What gets embarrassing in customer or internal reviews?
- Where do requirement IDs appear in Jira, test names, or CI output?
- What import format do you actually have?
- Who would need to approve use of this tool?
- Would local-only usage make this easier to try?

## Demo Questions

- Would a report like this help before a review?
- Which finding is useful?
- Which finding is noise?
- What would make this unusable?
- What is missing from the report?
- What would you need to trust an import result?

Do not ask only "would you use this?" Ask users to walk through their current workflow and compare Doorframe to that reality.
