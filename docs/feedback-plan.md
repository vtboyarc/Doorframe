# Feedback Plan

Start with 3 to 5 adjacent users who understand requirements, test evidence, or review prep.

## Approach

1. Ask the user to walk through their current workflow.
2. Ask where traceability breaks down.
3. Show the Falcon Telemetry Gateway demo.
4. Ask where the report helps and where it fails.
5. Ask what import format they actually have.
6. Ask whether local-only usage changes approval friction.

Do not ask "would you use this?" in isolation. Watch whether the report helps them explain a real workflow.

## Data Handling

Collect import examples only when sanitized and approved. Do not collect proprietary, sensitive, classified-sounding, or regulated data.

## Tracking

Track feedback as GitHub issues:

- import failure
- confusing finding
- missing report section
- demo confusion
- security/trust question
- documentation gap
