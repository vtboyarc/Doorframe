# Real-World Validation

Doorframe v0.1.0 is successful when the core workflow is understandable without explanation.

## Success Criteria

- A new user can run the Falcon demo in under ten minutes.
- A user understands the report without a walkthrough.
- A user can identify at least one real workflow where Doorframe would help before a review.
- Import errors are understandable and actionable.
- Docs do not create security or compliance confusion.
- Users understand that Doorframe is local-first and useful without AI.
- Users understand that MCP is optional and read-only.

## Failure Signals

- Users cannot tell what files to import.
- Users cannot explain the report.
- Users think Doorframe is a SaaS.
- Users think Doorframe certifies compliance.
- Users think Doorframe is approved for sensitive or classified data.
- Users cannot connect findings to review prep.
